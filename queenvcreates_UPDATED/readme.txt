QUEENVCREATES — FREE WEBSITE

FILES
- index.html = website
- style.css = pink design
- script.js = multi-step booking interaction
- images/nails-hero.webp = sample nail photo

TO PUT IT ONLINE FOR FREE WITH WORKING FORM SUBMISSIONS
1. Create a free Netlify account.
2. Create a new site from this folder, or connect a GitHub repository containing these files.
3. Make sure index.html is in the top level of the deployed folder.
4. Netlify detects the form because the HTML contains data-netlify="true".
5. After deployment, open your site and submit a test booking. Check Netlify's Forms area for the submission.

IMPORTANT
- Replace the sample phone number if needed.
- Replace the sample nail image with your own photos by putting them in /images and changing the image filename in index.html.
- The requested date/time is a REQUEST, not an automatic availability check. Confirm the appointment manually before treating it as booked.
- Do not put private customer information, payment card details, or passwords into the public GitHub repository.
